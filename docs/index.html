● 22 listas regulatorias · macOS & Windows

Consulta regulatoria por número CAS

Pega uno o varios números CAS y verifica al instante en qué listas e inventarios de químicos del mundo aparece cada sustancia. Resultados en una tabla comparativa exportable a Excel.

🍎 Descargar para macOS 🪟 Descargar para Windows Ver en GitHub

Características

Detección automática de CAS

Pega texto o prosa: detecta los números CAS y los convierte en chips, sin duplicados.

Importar CSV / Excel

Carga un archivo y extrae todos los CAS de cualquier columna u hoja.

Tabla comparativa

Una fila por CAS, una columna por lista (✓ / – / ⚠). Cada fila se expande con el detalle de cada fuente.

Exportar a Excel

Genera un .xlsx con Sí/No por lista más columnas de detalle (fecha de inclusión, sunset date, motivo…).

Consultas en paralelo

Las fuentes se consultan simultáneamente por host, respetando el límite de cada servidor.

Sin instalación en Windows

Versión portable: descomprime y ejecuta. En macOS, un .dmg estándar.
